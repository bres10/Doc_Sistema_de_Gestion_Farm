# VISIÓN DEL NEGOCIO
## Cadena de Farmacias - Expansión Nacional

### 1. Introducción

#### 1.1 Propósito
Definir la visión estratégica del negocio de la cadena de farmacias, sus 
objetivos, procesos clave y la forma en que el Sistema de Gestión Farmacéutica 
(SGF) soportará su expansión nacional y preparación para entrada a bolsa.

#### 1.2 Alcance
El negocio abarca:
- Operación de farmacias en centros comerciales
- Stands en gasolineras
- Distribución de medicamentos
- Servicio al cliente final
- Preparación para salida a bolsa

#### 1.3 Definiciones
| Término | Definición |
|---------|------------|
| Cadena | Conjunto de sucursales farmacéuticas |
| Stand | Punto de venta reducido en gasolinera |
| Centro Comercial | Mall con alta afluencia |
| Call Center | Centro de atención telefónica |
| IPO | Oferta Pública Inicial (bolsa de valores) |

### 2. Objetivos del Negocio

#### 2.1 Objetivos Estratégicos
1. **Expansión Nacional**: Cubrir los principales departamentos con centros comerciales
2. **Optimización de Infraestructura**: Aprovechar locales existentes en gasolineras
3. **Centralización Operativa**: Control único de todas las sucursales
4. **Auditoría en Tiempo Real**: Transparencia financiera para inversionistas
5. **Preparación IPO**: Cumplir requisitos para entrada a bolsa de valores

#### 2.2 Objetivos Específicos
| Objetivo | Métrica | Plazo |
|----------|---------|-------|
| Abrir 100 sucursales | Número de sucursales | 12 meses |
| Reducir desabastecimiento | % stock disponible | 6 meses |
| Optimizar entregas | Tiempo promedio entrega | 6 meses |
| Auditoría 100% operaciones | % operaciones auditadas | 9 meses |
| Preparar IPO | Cumplimiento requisitos | 18 meses |

### 3. Procesos de Negocio

#### 3.1 Procesos Principales
1. **Abastecimiento**
   - Compra a proveedores
   - Recepción en bodega central
   - Distribución a sucursales

2. **Venta**
   - Venta en mostrador
   - Venta por pedido telefónico
   - Venta por portal web (futuro)

3. **Distribución**
   - Transferencias entre sucursales
   - Entregas a domicilio
   - Coordinación con call center

4. **Control**
   - Auditoría de inventario
   - Auditoría de cajas
   - Auditoría de activos

5. **Administración**
   - Gestión de personal
   - Gestión de planilla
   - Gestión de gastos

#### 3.2 Procesos de Soporte
- Gestión de usuarios y roles
- Gestión de catálogo
- Gestión de precios
- Reportes gerenciales

### 4. Actores del Negocio

| Actor | Descripción | Interacción con SGF |
|-------|-------------|---------------------|
| Proveedor | Suministra medicamentos | Recepción de compras |
| Bodega Central | Almacén principal | Distribución |
| Gerente Regional | Supervisa región | Reportes |
| Gerente Sucursal | Administra local | Operación diaria |
| Cajero | Atiende clientes | Ventas |
| Bodeguero | Controla inventario | Movimientos |
| Operador Call Center | Atiende pedidos | Pedidos y entregas |
| Cliente Final | Compra medicamentos | Venta/Entrega |
| Auditor | Verifica operaciones | Consulta |
| Inversionista | Financia | Reportes financieros |

### 5. Reglas de Negocio

| ID | Regla | Descripción |
|----|-------|-------------|
| RN-01 | Caja abierta | No se puede vender sin caja abierta |
| RN-02 | Stock suficiente | No se puede vender sin stock |
| RN-03 | Lote y vencimiento | Todo medicamento tiene lote y fecha |
| RN-04 | Trazabilidad | Todo movimiento es registrado |
| RN-05 | Transferencia | Requiere solicitud y recepción |
| RN-06 | Precio | Precio de venta > precio de compra |
| RN-07 | Stock mínimo | Alerta al llegar al mínimo |
| RN-08 | Vencimiento | Alerta 30 días antes |
| RN-09 | Rol | Permisos según rol del usuario |
| RN-10 | Sucursal | Usuario solo ve su sucursal (excepto admin) |

### 6. Visión del Negocio con SGF

#### 6.1 Situación Actual
- Operación manual en cada sucursal
- Falta de control centralizado
- Inventario desactualizado
- Sin auditoría en tiempo real
- Entregas tardías

#### 6.2 Situación Deseada
- Plataforma única centralizada
- Inventario en tiempo real
- Auditoría automatizada
- Entregas coordinadas
- Reportes para inversionistas

#### 6.3 Beneficios Esperados
| Beneficio | Impacto |
|-----------|---------|
| Reducción de pérdidas | -30% |
| Mejora en entregas | -50% tiempo |
| Eficiencia operativa | +40% |
| Transparencia | 100% |
| Preparación IPO | Cumplimiento |
